**它做什么**：微软按席位把 Microsoft 365（含 Windows 商业版云端）、Dynamics 与 LinkedIn 人才与销售方案租给全球企业，并用 Azure 出租算力 [src:MSFT-10K-FY2026#p5]。FY2026 收入 3,318 亿美元，营业利润率 46.8% [src:MSFT-10K-FY2026#p50]。

**为什么是好生意**：席位生意所在分部 FY2026 每块钱收入近六毛是营业利润 [src:MSFT-10K-FY2026#p38]，客户要换掉它得迁移文件、重接身份、重建合规 [src:MSFT-RPT1-2026-09-17#p3]。企业买 Azure 也走同一合同、同一销售 [src:MSFT-RPT1-2026-09-17#p3]；FY2026 Azure 收入首超 1,000 亿美元 [src:MSFT-8K-2026-07-29#EX-99.1]。

**什么必须做对**：它首次把年金现金大举投入数据中心：FY2026 现金资本开支 1,159 亿美元、占收入 34.9%，自由现金流降到非 GAAP 净利润的 52.0% [src:MSFT-10K-FY2026#p53] [src:MSFT-10K-FY2026#p42]。投入要换来盈利增长，资本开支周期要回落，FY2026 末 6,780 亿美元商业积压订单 [src:MSFT-10K-FY2026#p77] 也要靠 OpenAI 以外的客户，OpenAI 在唯一一次披露中约占 45%（FY26 Q2，当时 6,250 亿美元）[src:MSFT-CALL-FY2026Q2]。

**什么会证明我错**：Azure 固定汇率增速连续两季低于 20% 而现金资本开支仍超收入的 25%，FY2028 按当年非 GAAP 口径的现金转换率低于 45%，微软云毛利率连续两季低于 58%，剔除 OpenAI 的履约余额增速低于 5% 或 2,500 亿美元承诺 [src:MSFT-8K-2025-10-29#EX-99.2] 被重组或减值，或席位下降而拿不出增长的 agent 或用量收入 [src:MSFT-RPT1-2026-09-17#p11] [src:MSFT-RPT1-2026-09-17#p12]。另三条要读文件：Nadella 离任且未披露继任安排，或 2027 年委托书长期激励仍无资本回报指标而现金资本开支仍超 1,500 亿美元 [src:MSFT-RPT1-2026-09-17#p12]；微软所持 OpenAI 股权减值，或 OpenAI 无法为算力承诺融资；欧盟《云与 AI 发展法案》生效后，Level 3 第三国认可通道对美国厂商实际关闭 [src:MSFT-RPT1-2026-09-17#p12]。
